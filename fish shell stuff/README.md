# 🐟 My fish config

I have quite a few things that I source here, and I also have optimizations (such as setting the history size, disabling internal autosuggestions to prevent conflict with [Lig](https://github.com/KevenGoncalves/lig), and escape & sequence delays), custom defaults, a ton of abbrs (most are for me personally), shortcuts, a few variables, etc. 

I main Fedora so I have shortcuts for DNF5-related files and operations.
